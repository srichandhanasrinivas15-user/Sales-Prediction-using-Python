# Sales Prediction using Python

## Project Overview

This project predicts sales based on advertising expenditure using Python and Machine Learning.

The dataset contains advertising spending on:
- TV
- Radio
- Newspaper

The target variable is Sales.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

- Linear Regression
- Random Forest Regression

## Project Steps

- Data Collection
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Feature and Target Selection
- Train-Test Split
- Model Training
- Model Evaluation
- Sales Prediction
- Feature Importance Analysis

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion

This project demonstrates how Machine Learning can be used to analyze advertising expenditure and predict sales.
